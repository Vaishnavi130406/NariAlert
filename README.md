# 🛡️ NariAlert – Women Safety Application

**A Flutter-Based Women Safety and Emergency Assistance Application**

## 📌 Project Overview

NariAlert is a women safety application designed to support personal security and provide assistance during emergency situations.

The project aims to use mobile technology to make safety assistance more accessible, convenient, and user-friendly. It focuses on creating a platform that can help women feel more secure in their daily activities and improve access to emergency support.

Built using Flutter, NariAlert is designed with a cross-platform approach to support multiple devices.

## 🎯 Project Objectives

- Promote women's safety through technology.
- Provide an accessible and user-friendly safety platform.
- Make emergency assistance easier to access.
- Explore technology-driven solutions for personal security.
- Develop a cross-platform mobile application.

## ✨ Key Areas

- **Personal Safety:** Focus on improving personal security.
- **Emergency Assistance:** Designed around emergency support requirements.
- **User-Friendly Interface:** Simple and accessible application experience.
- **Cross-Platform Development:** Built using Flutter for multiple platforms.

## ⚙️ Installation and Setup

### Prerequisites

Install the following:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or Visual Studio Code
- Git
- Android Emulator or physical device

### Step 1: Clone the Repository

```bash
git clone https://github.com/Vaishnavi130406/NariAlert.git
```

### Step 2: Navigate to the Project

```bash
cd NariAlert
```

### Step 3: Install Dependencies

```bash
flutter pub get
```

### Step 4: Check Flutter Setup

```bash
flutter doctor
```

### Step 5: Run the Application

```bash
flutter run
```

To run the application on a specific connected device, first check available devices:

```bash
flutter devices
```

## 🧪 Testing

Run the Flutter test suite using:

```bash
flutter test
```
